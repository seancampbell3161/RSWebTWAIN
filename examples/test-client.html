RSWebTWAIN test client

A dependency-free harness for driving the scan agent against a real scanner.

Serve this over http://localhost — do not open it as a file. A file:// page sends Origin: null, which the agent rejects. From this directory: python -m http.server 8080, then open http://localhost:8080/test-client.html. An https:// page cannot reach ws:// at all (mixed content), so a hosted copy will not work either.
